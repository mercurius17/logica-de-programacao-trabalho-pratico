# Lógica de Programação — Trabalho Prático

Trabalho prático da disciplina **Lógica de Programação**, do curso de
Engenharia de Software da UNINTER, desenvolvido por
**Pablo Henrique Oliveira Rodrigues**.

São quatro programas em Python, executados no terminal, cada um exercitando
um conjunto de conceitos da disciplina.

| Arquivo | Programa | Conceitos |
|---|---|---|
| `questao1.py` | Calcula a mensalidade de um plano a partir do valor base e da faixa etária do cliente | Entrada de dados, conversão de tipos, `if / elif / else` |
| `questao2.py` | Pedidos de uma pizzaria: escolha de sabor e tamanho, com soma do total | Laço `while`, `continue` / `break`, validação de entrada, acumulador |
| `questao3.py` | Orçamento de uma madeireira: tipo de madeira, quantidade com desconto progressivo e transporte | Funções com retorno, `try / except`, validação de entrada |
| `questao4.py` | Lista de contatos com cadastro, consulta (todos, por id, por atividade) e remoção | Listas, dicionários, funções, menus |

## Como executar

É preciso ter o [Python 3](https://www.python.org/downloads/) instalado.

```
python questao1.py
```

Troque o nome do arquivo para rodar as demais questões.
